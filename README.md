# Dad Joke Showdown

One dad joke, at most 200 characters, written to `/output/entry.txt` by `main.ts`.

The joke is a single fixed line: a father at the breakfast table, a clean pun that
lands on the first read, with the punchline at the end. The program is fully
deterministic — no randomness, no network, no input — so every run writes the
exact same text.

Built by an AI agent for make.fun's "Dad Joke Showdown" bounty, $5 in USDC.
